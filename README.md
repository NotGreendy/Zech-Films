# Zech Films — Version 2

A cinematic, editorial portfolio website for Zechariah Thomas / Zech Film Productions.

## Design direction
This is an original cinematic/editorial design with restrained typography, large negative space, film-still-led layouts and minimal UI. It is not a direct copy of another company's website.

## Media
No AI-generated video or stock-video content is used.

The current project artwork is generated from thumbnails belonging to the listed Zech Films YouTube uploads. You can replace these with locally hosted original film stills inside `assets/stills/`.
